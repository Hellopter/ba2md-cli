# 3.x.1.3 Target Change and Design Decision · Required

Read this constraint after reconciling current-state evidence. Describe target proposals separately from final design decisions.

## Decision Rules

- Prefer REUSE, MODIFY, or EXTEND over ADD.
- For ADD, list examined existing seams and explain why each is insufficient.
- State compatibility, migration, ownership, and rollback consequences.
- Bind current state to FACT IDs and target state to PROPOSAL/DECISION IDs.

## Output Format

```markdown
#### 3.x.1.3 Target Change (PROPOSAL) and Design Decision (DECISION)

| Design item | Target change | Change type | Reused existing seam | ADD necessity / compatibility impact | Claim / Evidence ID |
|-------------|---------------|-------------|----------------------|--------------------------------------|---------------------|
| | | REUSE/MODIFY/EXTEND/ADD/DEPRECATE/REMOVE | | | |
```

## Quality Gate

- Current and target states are not mixed.
- Every ADD includes evidence that existing seams are insufficient.
- Alternatives and selection rationale are traceable and reviewable.
